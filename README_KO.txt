내 가계부 PWA 설치 안내
======================

포함 기능
- 수입/지출 기록, 분류, 날짜, 메모
- 브라우저 localStorage 자동 저장
- 잔액 및 이번 달 수입/지출 요약
- 월별 통계와 지출 카테고리 막대그래프
- 월별 거래 조회, 수입/지출 필터, 내역 삭제
- 서비스 워커 캐시를 통한 오프라인 재접속 지원

중요: 이 폴더를 휴대폰에 다운로드하는 것만으로는 홈 화면 설치가 되지 않습니다.
PWA는 HTTPS 웹 주소로 배포해야 합니다(또는 localhost 개발 환경).

쉬운 배포 방법(예: GitHub Pages)
1. 압축을 풀고 파일들을 GitHub 저장소의 루트에 올립니다.
2. 저장소 Settings > Pages에서 배포할 브랜치와 /(root)를 선택합니다.
3. 생성된 https://...github.io/... 주소를 갤럭시 Chrome에서 엽니다.
4. Chrome 메뉴(⋮) > '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
   메뉴 이름은 Chrome 버전에 따라 다를 수 있습니다.

개인정보/저장 주의
- 내역은 서버로 전송하지 않고 현재 브라우저의 localStorage에 저장됩니다.
- 같은 기기라도 브라우저/사이트 데이터 삭제, 시크릿 모드, 다른 브라우저 사용 시 기록이 사라지거나 공유되지 않을 수 있습니다.
- 기기 변경 전에는 아직 내보내기/가져오기 기능이 없으므로 기록을 잃지 않도록 주의하세요.
- 잔액은 입력한 전체 내역의 수입 합계 - 지출 합계이며, 월별 통계는 선택한 월 기준입니다.
